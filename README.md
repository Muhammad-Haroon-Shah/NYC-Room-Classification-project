🏠 NYC Room Classification

A Machine Learning project that uses a trained model to classify room or property-related data through a Python application.

📌 Project Overview

The NYC Room Classification project uses a machine learning pipeline saved as a pickle (.pkl) file to make predictions based on input data. The project includes a Streamlit application for an interactive user interface.

✨ Features

Machine Learning prediction pipeline

Pre-trained model stored in Model_Pipeline.pkl

Interactive web interface using Streamlit

Python-based application

Easy to run locally

🛠️ Technologies Used

Python

Scikit-learn

Pandas

NumPy

Joblib / Pickle

Streamlit
